🔐 لوحة تحكم الموقع

محتاج "مفتاح وصول شخصي" (Personal Access Token) من GitHub، مرة وحدة بس — بعدها يتذكره المتصفح.

  1. افتح هذا الرابط وسجّل دخول بحساب alghuzii
  2. اضغط Generate new token
  3. بخانة Repository access اختر Only select repositories وحدد alghuzii.github.io
  4. تحت Permissions، افتح Contents واختر Read and write
  5. اضغط Generate token بالأسفل، وانسخ المفتاح (يبدأ بـ github_pat_)
